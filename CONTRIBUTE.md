# How to Contribute

Contributing is simple:
1. Branch off of the master branch (main)
2. Add your changes
3. Create a Pull Request
4. Ask someone to double check your changes
5. Merge! (or fix whatever issues your reviewer shares first)

## Environment Variables & External Dependencies
Given our app should be consistent accross deployments, we want to ensure we all develop the application with the same credentials and environment variables, to avoid behavior variance.

**Ask a staff member for the Environment Variables before contributing. These should be privately shared, so they're not publicly available in the repository.**

### Supabase
The database used is hosted in Supabase. They have a very generous free plan, which will be more than enough for our use case.

**Please ask a staff member for access to the Supabase project if needed.**
