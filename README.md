# HackTitan Website
This site contains information regarding the event, and it also handlesdummy change
registration.

## Event Information
The landing page contains all information needed for interested students to
navigate the event. This includes the event timeline, who can participate,
different tracks, sponsors, who is behind the event, where the event is taking place, etc. 

## Event Registration
The site should allow students to register without much friction. Given we are not going to be excessively rigorous when reviewing applications, there
shouldn't be a need for every single participant to create and log into an
account.

## Handling applications
After a user registers for the event, the form is saved in our database. Staff Members can view all applications after signing up and logging in.

## Staff Accounts
Staff accounts must be created using an IWU student account, along with the Staff Code, which is only available to staff members.
